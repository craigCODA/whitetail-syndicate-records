Whitetail Syndicate First Shirt Samples
Craig Ramos  |  September 22 2026
Where I Think We Should Start
I went through the four design files and put together how I think we should start. I'd order two black 
performance long-sleeve samples. The first would use the round seal on the back, the smaller emblem on 
the left chest, and the long design on the right sleeve.
The second shirt is the idea I came up with while working through the placements. I'd keep the small chest 
emblem, leave the sleeves clean, and move a larger version of the long design to the right side of the 
back. Hair normally falls through the center of the back, so this keeps the design visible and gives the shirt 
a different look without moving everything too low.
How I Would Use Each File
File 01 Flagship Seal
File size  12 x 12 inches at 300 DPI.  This is the round seal I'd use on the back of the first shirt. I'd place 
it lower than the usual upper-back logo so the name, skull, and lower wording have a better chance of 
staying visible.
File 02 Wide Back
File size  13.5 x 8.1 inches at 300 DPI.  This is the wider back option. I'd hold this one until we see how 
the first two samples turn out. If the shirt and print quality look right, this would be the next back design I'd 
try.
File 03 Compact Emblem
File size  4 x 4 inches at 300 DPI.  This is the smaller emblem for the left chest. I'd use it on both of the 
first samples so they still look like they belong to the same line even though the back designs are different.
File 04 Full Sleeve
File size  4 x 20 inches at 300 DPI.  This is the full-length right-sleeve design for the first shirt. I also want 
to use the same artwork as the starting point for the off-center back design on the second shirt.

First Sample
For the first shirt, I'd use Artwork 03 on the left chest, Artwork 04 on the right sleeve, and Artwork 01 
centered lower on the back. This gives us one sample with the regular chest, sleeve, and back layout so 
we can see the shirt material and print quality together.
Second Sample
For the second shirt, I'd use Artwork 03 on the left chest and leave both sleeves clean. I'd put a larger 
version of Artwork 04 vertically on the right side of the back. That keeps it out of the center area that hair 
is most likely to cover.
One More File I Need to Make
Artwork 04 is now built as a 4 x 20 inch full-sleeve file. For the second shirt, I still want to make a separate 
back version from the same design instead of using the sleeve file as-is. Once I have the allowed back 
print area, I can size that version correctly and keep it at 300 DPI.
What I Need Before Uploading
Before I upload anything, I need the exact shirt, color, cut, and sample sizes. I also need the print areas 
from whichever company we order through so I can set the files up for the actual shirt instead of guessing. 
Once the samples come in, we can check the placement, print quality, colors, and how they hold up after 
washing before putting them on the website.
Camo Stays Separate
I'd keep the camo line separate from these first shirt samples. The camo pattern still needs a clean repeat 
made for fabric and needs to be tested on the material for the top and pants. These four shirt files do not 
replace the camo repeat.
